Welcome all ACM MM 2009 participants!

Here you can download and try the implementation of the paper "Identifying Auxiliary Web Images Using Combination of Analyses" from the Multimedia Grand Challenge track.

The software is a firefox extension and it was written for Ubuntu Linux, but more versions for other platforms are coming soon!

DOWNLOAD: [auximg.xpi](/sites/default/files/auximg.xpi) - 120KB

UPDATE (22/10/09)

There's also another implementation that is independent from Firefox. I wrote it as a Python script that renders a Web page "headlessly" and then classifies the images. However, the computation takes quite long time so I stopped developing it and turned to Firefox add-on. The benefit of this script is that you might put it on the server or use the results in other applications.
